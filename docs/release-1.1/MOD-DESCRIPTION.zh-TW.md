# HD2 C4 Quick Actions 1.1

## 簡短介紹

用獨立按鍵投擲與引爆 C4，支援鍵鼠與手柄自訂操作。1.1 加入手動／接觸引爆模式、自動裝填，以及趴下、飛撲和載具乘客操作。

## 完整介紹

選用 C4 後，一個鍵投擲、一個鍵引爆，不需要反覆切換部署與引爆。按鍵和觸發方式都交由 Mod Bindings Menu 設定，支援鍵盤、滑鼠、Xbox 與 PlayStation 手柄，不需要按 F6 啟用。

### 1.1 更新內容

- **手動／接觸引爆模式**：在遊戲原本的 C4 武器設定選單切換。手動模式由你決定引爆時機；接觸模式在 C4 碰到物體後自動引爆，飛行途中仍可手動提前引爆。
- **完整採用 Mod Bindings Menu**：投擲與引爆各自設定按鍵及觸發方式，也可以使用放開投擲。不再區分 Standard／Reversed 安裝包。
- **趴下與飛撲操作**：趴下、飛撲及離地過渡時可以投擲或引爆。
- **載具乘客操作**：支援 FRV 與坦克乘客座位。按投擲鍵會自動探身，等完整投擲動作結束後再收回。
- **自動裝填**：投擲後有備用彈藥時自動裝填；打空後取得補給也會補裝填。支援載具乘客，並處理車內裝填被打斷後的下車恢復。切槍、操作介面等動作可以中斷裝填。
- **更流暢的投擲**：投擲與引爆鍵不會連帶觸發原本的越肩瞄準；使用「放開投擲」時，按住期間保留瞄準。也修正投擲鍵與開火鍵重疊時打斷奔跑的問題。
- **修正誤觸**：操作介面、戰術地圖或武器設定選單時，不會因為按到綁定鍵而投擲或引爆。修正切換引爆模式消耗手中 C4 的問題。

### 使用方式

在 MODS 按鍵頁設定 **Throw C4** 和 **Detonate C4**，再選用 C4 開始操作。引爆模式在遊戲原本的 C4 武器設定選單中選擇：

- **MANUAL／手動引爆**：投擲後，用引爆鍵引爆。
- **CONTACT／接觸引爆**：碰撞後自動引爆，也能在碰撞前手動引爆。

每顆 C4 保留開始投擲時的模式，切換模式不會改變已投出的炸彈。手動引爆沿用遊戲原本引爆自有炸彈的行為。已投出的接觸 C4 在切槍或開啟地圖後仍會依碰撞引爆。

### 安裝需求

- Bingus Shared Loader **v17+／API 1**。
- 官方 Mod Bindings Menu **v2+／API 1**。
- **HD2 Mod Manager 1.3** 或 **HD2 Arsenal**，兩者使用同一份 ZIP。

### 安裝步驟

1. 退出遊戲，安裝並啟用上述依賴模組。
2. 停用或移除舊版 C4 Quick Actions，包括 Standard／Reversed 版本。
3. 匯入 `HD2-C4-Quick-Actions-1.1.zip`。
4. 選擇 **Installation → C4 Quick Actions — MBM controls**，完成部署。
5. 進入遊戲，在 MODS 按鍵頁設定投擲與引爆。

同時只啟用一個 C4 Quick Actions 版本。移除時，在管理器停用或刪除模組後重新部署。

### 相容性說明

載具功能適用於乘客座位，不包含駕駛位。布娃娃狀態不接受新的投擲或引爆操作。

本模組沒有鎖定特定遊戲版本號。若更新改變了使用到的內部函式或資料結構，仍可能需要更新模組。

若 MODS 頁沒有出現按鍵，請確認兩個依賴模組及本模組都已啟用、部署，再重新啟動遊戲。
