HD2 C4 Quick Actions
Version 1.13

ENGLISH

Release 1.13. Features and controls are those of 1.12; the addon now needs far
fewer memory reads and less bookkeeping per frame to perform the same checks.
Measured in the game: about 0.14 ms per frame with C4 in hand, about 0.05 ms
with any other weapon.

Separate, customizable C4 throw and detonate actions for keyboard, mouse,
Xbox and PlayStation controllers through Mod Bindings Menu.

Requirements
- Bingus Shared Loader v17+ / API 1 (internal version 16 or newer).
- Official Mod Bindings Menu v2+ / API 1.

Installation — HD2 Mod Manager 1.3 or HD2 Arsenal
1. Exit the game and enable the dependencies above.
2. Replace your old C4 Quick Actions package with this ZIP.
   Keep only one C4 Quick Actions package enabled.
3. Deploy and restart. No installation options need to be selected.
4. Configure Throw C4 and Detonate C4 in the MODS bindings menu.
   Existing MBM bindings are retained; no F6 activation is required.

Both managers use the same ZIP. To uninstall, disable/remove it and redeploy.
This release does not write C4 diagnostic logs or expose diagnostic options.
Existing logs from older versions are not deleted.

Modes and features
- Choose Manual or Contact in the C4 weapon-settings menu. Contact charges
  detonate on physical contact; manual detonation still works during flight.
- Each charge retains the mode selected when thrown. Previously thrown Contact
  charges keep working after switching weapons or opening an interface.
- Throw and detonate while prone or diving, and from FRV/tank passenger seats.
  Passengers stay leaned out for the complete throw before returning inside.
- Automatically reload after throwing or receiving supplies when empty.
  Other player actions can interrupt reload.
- Mod actions suppress vanilla shoulder aim, except while holding a
  release-to-throw binding.
- Interfaces, tactical map and ragdoll states block new throw/detonate actions.


繁體中文

正式版 1.13。功能與操作同 1.12；完成同樣檢查所需的記憶體讀取與每幀簿記大幅減少。
遊戲內實測：手持 C4 每幀約 0.14 ms，手持其他武器約 0.05 ms。

HD2 C4 Quick Actions 1.13
透過 Mod Bindings Menu 自訂獨立的投擲和引爆操作，
支援鍵盤、滑鼠、Xbox 與 PlayStation 手柄。

需求
- Bingus Shared Loader v17+／API 1（內部版本值 16 以上）。
- 官方 Mod Bindings Menu v2+／API 1。

安裝：HD2 Mod Manager 1.3 或 HD2 Arsenal
1. 退出遊戲，啟用上述依賴模組。
2. 用本 ZIP 替換舊版 C4 Quick Actions，
   同時只啟用一個 C4 Quick Actions。
3. 部署並重新啟動遊戲，不需要選擇任何安裝選項。
4. 在 MODS 按鍵頁設定 Throw C4 和 Detonate C4。
   原有 MBM 綁定會保留，不需要按 F6 啟用。

兩個管理器使用同一個 ZIP。移除時停用／刪除本模組並重新部署。
本版不寫入 C4 診斷日誌，選單沒有診斷選項；舊版留下的日誌不會刪除。

模式與功能
- 在 C4 武器設定選單選擇手動或接觸引爆。接觸炸彈碰到物體時引爆，
  飛行途中仍可手動引爆。
- 每顆炸彈保留投出時的模式；已投出的接觸炸彈在切槍或開啟介面後仍有效。
- 趴下、飛撲及 FRV／坦克乘客位可投擲和引爆，完整投擲後才返回車內。
- 投擲後或打空後取得補給時自動裝填，其他操作可中斷裝填。
- 操作不觸發原生越肩瞄準；按住放開時投擲的綁定時保留瞄準。
- 操作介面、查看地圖與布娃娃狀態會阻擋新的投擲／引爆操作。
