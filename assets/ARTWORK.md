# Cover artwork

[Cover](cover.png) · [Source frame](cover-source.png) · [Exact editing prompt](cover-prompt.txt)

The source is a frame at **00:17.500** from the gameplay video supplied by the repository owner. It shows the C4 backpack and throwing pose with an existing explosion in the desert. The original video is not bundled.

The cover was made with the built-in `image_gen` tool. The requested edits were HUD removal and a simple charcoal title panel reading **HD2 / C4 / QUICK / ACTIONS**, while preserving the real gameplay composition. It is AI-assisted cover artwork based on a real frame, not an untouched screenshot. The source frame and full prompt are included so the design can be inspected or remade.

This image is presentation artwork, not additional gameplay validation. Helldivers 2 game imagery retains its original rights; the project's MIT code license does not relicense the game's artwork.
